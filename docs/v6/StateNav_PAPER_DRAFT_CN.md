## 摘要

现有视觉语言导航智能体在长程连续执行中常出现一个根本性缺陷：它们能够在局部观测上做出合理动作，却缺乏稳定的内部自检机制，因此难以及时识别“自己已经偏离预期”。这一问题在 VLN-CE 场景中尤为突出，因为连续位姿变化会带来大量局部视觉冗余，而真正决定成功与否的往往是少数关键节点处的路线偏离与恢复能力。本文提出 `StateNav`，一种用于视觉语言导航自我诊断与宏观干预的分层自我模型。该方法在同一系统中引入两个互补层次的内部预期：微观层保留基于 RSSM 的时间连续自我模型，用于刻画局部动态下的先验-后验失配；宏观层引入基于拓扑节点的长期记忆结构 `TopoStateBank`，并通过 `NodeSurpriseHead` 预测节点级特征，从而构建预期与现实之间的宏观失配。我们进一步将二者融合为统一的自我诊断信号，并将其显式接入宏观干预模块，以控制继续前进、候选扩展、恢复回退和停止等恢复行为。与将世界模型单独作为预测器或将风险单独作为打分器的做法不同，`StateNav` 的核心目标不是提高单一预测精度，而是形成一个可解释、可干预、可分析的自我诊断闭环。本文的贡献可归纳为三点：其一，提出一个由微观时序层和宏观拓扑层组成的分层自我模型；其二，提出基于节点预期-现实偏差的宏观自检信号，并将其与微观 latent mismatch 融合；其三，将融合后的自我诊断信号直接连接到宏观干预机制，形成从偏航发现到恢复决策的完整闭环。本文给出完整的方法定义、训练目标、消融矩阵和实验分析框架，为后续在 R2R 上验证长程偏航检测与恢复能力提供统一基线。

**关键词：** 视觉语言导航，自我模型，自我诊断，宏观干预，世界模型，拓扑记忆

## 1. 引言

**界定问题。** 视觉语言导航（Vision-and-Language Navigation, VLN）要求智能体根据自然语言指令在三维环境中连续执行导航动作。近年来，基于 transformer、图规划和 waypoint 预测的 VLN 系统在局部决策上取得了持续进展，但长程连续执行中的稳定性问题依然突出：模型往往并不是“不会走”，而是“走错了却不知道自己已经走错”。当系统在一段走廊中持续前进，或在大房间中经历较长的连续位姿变化时，其内部状态会不断吸收新的观测，但这些观测中大量是冗余且局部相似的；一旦早先对关键路口、目标方向或当前任务阶段的判断出现偏差，模型常常缺乏可靠的内部证据来触发恢复机制，最终表现为偏航、循环、过早停止或回退失败。

**指出缺陷。** 这一问题揭示了现有 VLN 智能体的一个共性短板：它们具备外部感知与规划能力，却缺乏稳定的内部自检能力。已有方法通常沿两条路径处理这一问题。第一类路径使用 world model 或 latent dynamics 近似建模未来演化，希望通过预测误差或先验-后验偏差衡量当前状态是否异常；第二类路径直接学习一个不确定性或风险分数，并在高风险时触发重新规划或恢复策略。前者的问题在于，VLN-CE 的核心难点并不等同于高频时间连续控制：连续帧之间的冗余会稀释关键决策点信息，使纯时间轴上的内部状态更新更容易积累噪声；后者的问题在于，单纯回归一个标量风险值往往缺乏稳定的结构性依据，难以在新环境下保持可靠性，也难以解释模型为何要干预。

**对症下药。** 本文提出 `StateNav`，以分层自我模型的方式统一处理上述两个问题。我们的出发点是：VLN 智能体的内部自检不应只发生在每一个时间步，也不应只依赖一个外部学习到的风险分数，而应同时在两个层次上形成“内部预期 vs. 外部现实”的比较。具体来说，我们保留微观时间层的 RSSM，用于建模局部连续执行中的先验-后验失配；同时在宏观层引入基于拓扑节点的长期状态记忆，只在关键节点或兜底触发点更新长期状态，并预测下一拓扑节点的特征表示。当真实观测与该预测发生明显偏离时，系统获得一个更具结构性的宏观自检证据。我们进一步将微观失配与宏观失配融合成统一的自我诊断信号，并将其显式连接到宏观干预模块，从而把“发现自己可能走错了”直接转化为“如何恢复”。

与把拓扑图本身作为贡献终点的思路不同，本文中的拓扑记忆只是一种支持自我诊断的基础设施；与将世界模型单独视为预测器的做法不同，我们并不把节点预测本身作为最终目标，而是把它作为宏观层面的自检证据；与仅仅报告干预收益的工作不同，我们强调诊断信号的来源、层次与可解释性。基于这一设计，本文的核心贡献可以概括为三点：

1. 我们提出一种分层自我模型框架，将微观时序失配与宏观拓扑失配统一为单一的自我诊断信号，用于描述智能体当前 belief 与现实之间的割裂程度。
2. 我们提出基于拓扑节点的自我诊断机制，通过对关键节点处的预期-现实偏差进行建模，增强长程导航中的偏航检测能力，并避免将连续时间噪声误判为迷路信号。
3. 我们将分层诊断信号显式接入宏观干预模块，形成从诊断到恢复的闭环，并给出完整的训练目标、消融矩阵和分析框架，使该系统能够被系统性验证而不仅仅作为工程 heuristic 使用。

## 2. 相关工作

### 2.1 视觉语言导航与具身决策

视觉语言导航旨在根据语言指令引导智能体完成长程导航任务。早期工作主要围绕序列决策、teacher forcing、环境交互与语言 grounding 展开，后续方法进一步引入图结构、候选 waypoint 选择和 transformer 编码，以提升对复杂环境的建模能力。特别是在 VLN-CE 场景中，很多方法已经能够构建较强的外部 planner 或图搜索流程，在候选生成、局部选择和路径规划方面表现稳定。

然而，现有系统的主干能力大多集中在“如何往前选动作”，而不是“如何判断自己已经偏离预期”。当环境反馈与内部 belief 不一致时，这些系统通常依赖外部重新打分、简单回退规则或启发式门控，而缺乏一个结构化的内部自检模块。本文关注的正是这一层缺失：不是替代现有 planner，而是在 planner 之上增加自我诊断与恢复层。

### 2.2 世界模型、预测误差与自我监控

世界模型和 latent dynamics 在强化学习与具身智能中被广泛用于建模内部动态、辅助规划或提供不确定性估计。典型做法是通过先验-后验的 latent mismatch、重建误差或未来预测误差来反映模型对当前状态的自洽程度。这类思想为自我监控提供了基础，因为内部预测与现实观测之间的偏差天然可以被解释为一种“模型不再理解当前世界”的信号。

但将这一思路直接移植到 VLN-CE 并不充分。原因在于，VLN 的关键困难并不是连续时间控制本身，而是长程导航中由少数关键节点决定的拓扑偏航。若仅沿时间轴对每一步进行 latent 预测，连续帧中的冗余观测容易冲淡关键节点的结构性信息，使内部失配既可能过于频繁，也可能在真正需要恢复时不够敏感。本文并不否定时间连续 world model，而是将其保留为微观自我模型，再在宏观层加入拓扑节点级的预测误差，以形成更稳健的自我诊断结构。

### 2.3 干预、恢复与层级控制

许多导航与机器人系统在局部策略不可靠时，会通过重规划、回退、候选扩展或停止动作等方式实现恢复。部分工作显式设计多级干预策略，依据打分阈值或异常检测信号在局部推进与宏观恢复之间切换。这类方法说明：恢复机制本身是长程任务成功的重要组成部分，特别是在环境噪声、候选不完整或语言对齐不充分的情况下。

然而，很多已有恢复策略只定义“触发条件”，而没有说明触发条件来自何种内部认知割裂；或者只依赖一个学习到的风险分数，缺少可解释的来源。本文的区别在于：我们不把干预视为后处理 heuristic，而把它视为自我诊断闭环中的决策层。系统先在微观和宏观两个层次上形成内部预期，再把失配结果统一成一个诊断信号，最后由宏观干预模块基于该信号执行恢复。这使得恢复行为有了更明确的内在依据。

## 3. 方法

### 3.1 问题定义

我们考虑 R2R 任务中的视觉语言导航设定。给定自然语言指令 $I$ 和环境中的当前观测，智能体需要在一系列离散导航动作中选择下一步行为，最终到达目标位置。系统在每一步接收视觉观测、图结构候选以及语言上下文，并在此基础上生成动作分数。

本文不替代现有外部 planner。我们把现有 ETP 风格主导航器视为底层 backbone，其负责候选构造、环境编码和基础动作分数。`StateNav` 作为上层的 self-model / self-diagnosis / macro-intervention layer，负责三个问题：

1. 当前内部 belief 与现实观测是否仍然一致；
2. 如果不一致，这种不一致是局部短时的，还是在宏观节点上已经发生偏航；
3. 在检测到失配后，系统应该继续、扩展候选、恢复回退，还是停止。

### 3.2 总体框架

`StateNav` 的总体数据流可以写成：

`micro self-model -> topo self-model -> fused diagnosis -> macro intervention`

具体而言：

1. 微观层基于 step-wise RSSM 建模局部连续动态，得到当前时间步的 latent mismatch；
2. 宏观层维护一个只在关键节点更新的 `TopoStateBank`，并预测下一节点的特征表示；
3. 系统将微观失配与宏观失配融合为统一的自我诊断信号；
4. 该诊断信号被送入宏观干预模块，用于控制继续前进、候选扩展、恢复回退和停止。

**图 1 占位说明。**
图 1 应展示四段式流程：左侧是 ETP backbone 输出候选与观测特征；中间上支是 micro RSSM，输出 $D_t^{\mathrm{latent}}$；中间下支是 TopoStateBank 与 NodeSurpriseHead，输出 $D_t^{\mathrm{node}}$；右侧是 $D_t^{\mathrm{fused}}$ 进入 MacroInterventionManager，并反馈到候选动作选择与恢复逻辑。图中应使用三个显著高亮框，对应摘要和引言中的三个创新点：分层自我模型、节点级自检、诊断驱动干预。图中不应把 topo graph 画成视觉中心，而应突出 `self-diagnosis -> intervention`。

### 3.3 微观时间层自我模型

在微观层，我们保留 step-wise RSSM，用于刻画局部连续运动中的内部状态更新。设前一时刻的隐状态和 latent 分别为 $(\boldsymbol{h}_{t-1}, \boldsymbol{z}_{t-1})$，当前动作、观测特征和图上下文分别为 $\boldsymbol{a}_{t-1}$、$\boldsymbol{x}_t$ 和 $\boldsymbol{g}_t$。微观自我模型包含以下三个阶段：

\[
\boldsymbol{h}_t^{-} = \mathrm{Transition}(\boldsymbol{h}_{t-1}, \boldsymbol{z}_{t-1}, \boldsymbol{a}_{t-1}),
\]

\[
\boldsymbol{h}_t^{+} = \mathrm{Correction}(\boldsymbol{h}_t^{-}, \boldsymbol{x}_t, \boldsymbol{g}_t),
\]

\[
\boldsymbol{z}_t \sim q(\boldsymbol{z}_t \mid \boldsymbol{h}_t^{-}, \boldsymbol{h}_t^{+}, \boldsymbol{x}_t, \boldsymbol{g}_t).
\]

其中 $\boldsymbol{h}_t^{-}$ 表示当前时刻基于先前内部状态得到的 prior belief，$\boldsymbol{h}_t^{+}$ 表示观测修正后的 posterior belief。我们将 prior 与 posterior 的 latent 失配定义为：

\[
D_t^{\mathrm{latent}} = \mathrm{KL}\big(q(\boldsymbol{z}_t \mid \boldsymbol{h}_t^{-}, \boldsymbol{h}_t^{+}, \boldsymbol{x}_t, \boldsymbol{g}_t) \,\|\, p(\boldsymbol{z}_t \mid \boldsymbol{h}_t^{-})\big).
\]

该量描述了当前局部现实对内部 belief 的纠偏强度。若 $D_t^{\mathrm{latent}}$ 较低，说明当前局部动态仍然符合模型已有预期；若其升高，则意味着系统在微观层面出现了不一致。但我们并不将其直接视为最终的迷路信号，因为它仍然主要依赖时间连续过程，可能受到连续视觉冗余的影响。

### 3.4 宏观拓扑层自我模型

为了使系统在关键节点处获得更稳定的长期记忆，我们引入 `TopoStateBank`。与逐步更新时间隐状态不同，`TopoStateBank` 并不在每一步都写入新状态，而只在满足拓扑更新门控时才更新。每个环境实例维护以下 runtime state：

- `topo_state`：当前已提交的拓扑节点状态；
- `topo_feat`：与该拓扑节点对应的节点特征；
- `last_vp_id`：最近一次提交节点的拓扑标识；
- `micro_step_count`：自上次拓扑提交以来经历的微观步数；
- `has_state`：当前是否已有有效的拓扑状态。

拓扑更新门控满足以下任一条件时触发：

1. 当前环境尚未建立任何拓扑状态；
2. 当前 `cur_vp` 与已提交节点的 `last_vp_id` 不同；
3. 局部候选数达到决策点阈值；
4. 当前观测与已缓存节点特征之间的 topo novelty 超过阈值；
5. 连续微观步数超过上限 `max_k`，需要进行弱刷新以防止长走廊中的状态塌缩。

在第一版实现中，topo novelty 定义为：

\[
\mathrm{novelty}_t = 1 - \cos(\boldsymbol{f}_t^{\mathrm{pano}}, \boldsymbol{f}_{t}^{\mathrm{topo}}),
\]

其中 $\boldsymbol{f}_t^{\mathrm{pano}}$ 是当前全景平均特征，$\boldsymbol{f}_t^{\mathrm{topo}}$ 是最近一次已提交拓扑节点的缓存特征。该设计的目的不是构造精细地图，而是为自我诊断提供一个稀疏、稳定的宏观记忆坐标。

### 3.5 节点惊奇度与分层自我诊断

仅有拓扑记忆还不足以形成宏观自检。为此，我们进一步引入 `NodeSurpriseHead`。设上一已提交拓扑状态为 $\boldsymbol{s}_{t-1}^{\mathrm{topo}}$，则该模块预测当前应当到达节点的特征表示：

\[
\hat{\boldsymbol{f}}_t^{\mathrm{node}} = \mathrm{NodeSurpriseHead}(\boldsymbol{s}_{t-1}^{\mathrm{topo}}).
\]

真实节点特征由当前观测获得，记为 $\boldsymbol{f}_t^{\mathrm{node}}$。在满足 `topo_valid_mask` 与 `topo_update_mask` 的位置上，我们用 feature-space MSE 定义节点惊奇度：

\[
D_t^{\mathrm{node}} = \lVert \hat{\boldsymbol{f}}_t^{\mathrm{node}} - \boldsymbol{f}_t^{\mathrm{node}} \rVert_2^2.
\]

与逐步时间预测不同，$D_t^{\mathrm{node}}$ 只在关键节点或兜底刷新点上生效，因此它更像“在路口检查自己是否仍然走在预期路线上”的信号，而不是每一步都对视觉变化做高频告警。

最终，我们将微观层与宏观层的诊断信号融合为统一的自我诊断量：

\[
D_t^{\mathrm{fused}} = \alpha \cdot D_t^{\mathrm{latent}} + \beta \cdot D_t^{\mathrm{node}}.
\]

其中 $\alpha$ 与 $\beta$ 为可配置权重。在当前实现中，默认取 $\alpha = 1.0$，$\beta = 1.0$。这一融合的含义是：微观层负责捕捉局部执行中的内部不自洽，宏观层负责捕捉关键节点上的路径预期失真，二者共同定义系统当前的自我失察程度。

### 3.6 宏观干预策略

`StateNav` 的最终目标不是报告一个诊断分数，而是在诊断信号升高时触发有效恢复。为此，我们将 $D_t^{\mathrm{fused}}$ 直接送入宏观干预管理器 `MacroInterventionManager`。该模块并不替代底层 planner，而是在 planner 输出的候选分数之上执行多级控制。当前实现中，宏观干预仍保留三级结构：

- **Level 1：** 继续当前行为模式，仅在原有严格候选集上进行决策；
- **Level 2：** 当诊断信号升高但尚未达到恢复级别时，扩展候选范围，提升对 frontier 的探索能力；
- **Level 3：** 当诊断信号持续较高且满足恢复策略条件时，执行恢复、回退或停止相关的宏观动作切换。

在本文主线中，宏观干预的触发依据来自分层自我诊断，而不再依赖 V5 时代的 curve / attention health 主分支。换言之，`StateNav` 的核心闭环是：

`内部预期 -> 现实修正 -> 诊断信号 -> 宏观恢复`

而不是：

`候选打分 -> heuristic 规则 -> 恢复`

### 3.7 训练目标

本文采用单阶段训练，整体目标为：

\[
L_{\mathrm{total}} = L_{\mathrm{plan}} + \lambda_{\mathrm{micro\_kl}} L_{\mathrm{micro\_kl}} + \lambda_{\mathrm{node\_surprise}} L_{\mathrm{node\_surprise}}.
\]

其中：

- $L_{plan}$ 为基于 teacher-forcing 的动作交叉熵；
- $L_{micro\_kl}$ 为微观 RSSM 的 latent KL；
- $L_{node\_surprise}$ 为拓扑更新位置上的节点特征 MSE。

当前配置中：

- $\lambda_{micro\_kl} = 0.1$
- $\lambda_{node\_surprise} = 0.5$

值得强调的是，本文主线不再使用旧主线中的 `curve_loss` 和 `attn_loss` 作为训练目标。原因并不是这些量在历史版本中没有价值，而是本工作的方法中心已明确转向“分层自我诊断驱动干预”，因此训练目标也必须与这一中心保持一致。

## 4. 实验

### 4.1 实验目标与设定

本文的实验目标不是只证明某个额外模块可以提高单步预测，而是从三个层面验证 `StateNav` 的设计是否成立：

1. 它是否能在主导航指标上维持或提升整体性能；
2. 它是否能在消融下体现出分层自我模型各组成部分的独立价值；
3. 它是否能在案例和诊断统计上展示“发现偏航并成功回正”的行为闭环。

2. **现有 StateNav 主线基线**

### 4.7 失败案例分析

除了成功回正案例，本文还必须显式分析失败案例，以界定方法边界。建议至少固定两类失败情形：

1. **节点边界失真失败。** waypoint / graph 流程未能在关键位置形成稳定节点，导致 `TopoStateBank` 提交位置滞后或错误，进而削弱宏观自检质量。
2. **恢复不足失败。** 系统已经检测到较高的 $D_t^{\mathrm{fused}}$，但由于候选集不完整、环境几何约束或恢复策略切换时机不佳，最终仍未成功回正。

失败分析的写作要求是：必须同时展示 baseline 与本文方法的差异，明确指出失败发生在哪个链条环节，是“没有发现错误”还是“发现了错误但恢复失败”。这部分不只是补充材料，而是验证本文主线边界的重要证据。

## 5. 讨论

### 5.1 为什么本文不是建图论文

虽然本文引入了 `TopoStateBank`，但其功能仅是为自我诊断提供稳定的长期记忆支点，而不是构建一个精细的显式地图。我们并不把 graph quality、节点覆盖率或拓扑结构最优性作为贡献终点，也不以此替代底层 planner。相反，拓扑记忆只在一个非常明确的链条中发挥作用：帮助系统在关键节点处形成更可信的预期，并将偏离预期的证据反馈给干预策略。

### 5.2 为什么本文不是单纯的世界模型预测论文

本文同样不以提高节点特征预测本身为最终目标。`NodeSurpriseHead` 的作用是为宏观层自我诊断提供证据，而非单独构建一个世界模型 benchmark。即使未来节点预测足够准确，如果系统不能把预测偏差转化为有效恢复，它仍然无法解决本文关注的核心问题。因此，本文的最终评价标准应始终围绕“是否更早发现偏航、是否更有效触发恢复、是否更稳定完成导航”来展开。

### 5.3 局限性

当前版本存在三个明确边界。第一，本文当前只覆盖 R2R 主线，尚未将 RxR 或更复杂语言分布纳入统一结论。第二，`TopoStateBank` 仍然依赖现有 waypoint / graph 流程提供的节点边界，因此当节点定义质量下降时，宏观层自检效果可能受到影响。第三，节点惊奇度当前使用 feature-space MSE，而非更完整的概率式建模，这使其解释力与鲁棒性仍有提升空间。这些局限不会推翻本文主线，但它们决定了本文应该把贡献表述为“更可信的分层自我诊断框架”，而不是“已经解决具身导航中的全部自我意识问题”。

## 6. 结论

本文提出 `StateNav`，一种面向视觉语言导航的分层自我模型。其核心思想不是把拓扑图或世界模型当作独立目标，而是在微观时序层与宏观拓扑层同时形成内部预期，并通过预期与现实的失配构造统一的自我诊断信号。该信号进一步驱动宏观干预模块，使系统能够在长程导航中更有依据地判断自己是否偏航，以及是否需要扩展候选、恢复回退或停止。围绕这一主线，本文完成了三件相互对应的工作：构建分层自我模型、提出节点级自检信号、建立诊断驱动的干预闭环。后续工作的重点将是补齐 R2R 实验结果、完善成功与失败案例分析，并进一步验证该分层自我诊断机制在更复杂任务中的泛化能力。
