# ASM-VLN 最终白皮书 v3

## Active Self-Model for Vision-Language Navigation

### 一、从直觉到范式

**最初的直觉（从未错过）** 别人建外部世界模型（预测环境会怎么变），我们建内部自我模型（预测自己会不会走坏）。

**走偏过的地方（复盘）**

* **自我模型 → 服务重排**
  * 【原因】：太早问"怎么用"，没先问清楚"它是什么"。
  * 【修正】：自我模型的价值是预测自身退化，重排是副产品。
* **复盘器找best_idx循环论证**：用环境距离做GT，完全外部。
* **imagination rollout在latent space模拟环境动态，本质是世界模型**
  * 【修正】：换成self-state rollout，预测自己，不预测环境。
* **health = mean(curve)丢失时序结构**
  * 【修正】：分解成early/late/trend动态加权。
* **SelfStateHead监督"当前在哪"，和"预测未来"矛盾**
  * 【修正】：删掉，换成ProgressCurvePredictor。
* **D_t大 → 退回planner**
  * 【原因】：候选集整体不可信时，换打分方式没用。
  * 【修正】：D_t大 → 分级宏观干预，不是退回planner。
* **L_attn被降级为正则**
  * 【原因】：误判为冗余。
  * 【修正】：L_attn和L_kl对称，是独立贡献，不应降级。

### 二、核心哲学

**物质与意识的辩证关系**

* **传统世界模型：** 预测外部世界（物质）会怎么变。 agent只是一个被动执行器。 公式：`world_t → world_{t+1}` 缺少主体，缺少意识。
* **ASM-VLN（我们的范式）：** 物质决定意识：`x_t`, `g_t`（外部环境）, `L`（语言指令） → 输入`s_t`的计算。 意识反作用于物质：`s_t → health_k → score_final → 影响导航行为`。 agent是主体，不是执行器。 公式：`Relation(agent, world, instruction)_t → Relation(agent, world, instruction)_{t+1}`

**s_t 的正式定义**`s_t` 不是世界状态的编码，不是agent内部状态的编码，而是：

> "内部意识（Query）主动检索外部环境与指令（Key/Value）之后产生的关系状态（Relational State）"

三个维度构成这个关系：

1. **我在环境里走到哪了？** → progress（物理世界锚点）
2. **当前环境、指令进度与我的预期匹配吗？** → D_t（认知与现实的三元匹配度差距）
3. **这个匹配关系继续走下去会怎样？** → progress curve & attention shift（关系的未来走势）

诞生于世界：需要 `x_t`, `g_t`, `L` 作为物质基础。 超出世界：不等于世界的镜像，包含agent对环境与指令的主动理解。

**和世界模型的根本区别**

* **世界模型问：** 走向candidate k，环境会变成什么？
  * output: next world state（没有agent，没有指令）
* **ASM-VLN问：**走向candidate k，我、环境与指令进度的匹配关系会变成什么？
  * output: next relation state（agent是核心，指令是对齐标尺）

这不是工程上的小改进，而是建模对象的范式转变：**从预测物质，到预测智能体、环境与指令的三元关系。**

### 三、完整架构

**总体数据流**

```text
ETP输出（冻结）：
  x_t（全景视觉）, g_t（全局图，含frontier节点）
  L（指令tokens）, f_{t,k}（候选节点特征）
  score_base_k（ETP原始打分）
         ↓
RSSM（已有）：
  attn_prior, h_prior
  attn_post,  h_post
  z_post, D_t
         ↓
D_t分级判断（新）：
  低D_t → 进入正常Phase 1-4流程
  中D_t → 候选集扩展至frontier节点
  高D_t → 触发STOP/BACKTRACK宏观干预
         ↓
Phase 1：当前关系状态提取 (看清现在)
  s_t = RelationalStateExtractor(internal=[h_post, z_post], external=[x_t, g_t])
         ↓
Phase 2：候选条件驱动的统一关系推演 (Candidate-Conditioned Unified Rollout)
  【一次推演，双轨读出】
  A. 统一关系表示: u_next_k = UnifiedRolloutTrunk(query=[h_next_k, z_next_k], memory=[world, f_tk])
  B. 物理状态读出: s_next_k = StateHead(u_next_k) -> curve_k = CurvePredictor(s_next_k)
  C. 语义焦点读出: predicted_attn_k = AttentionHead(attn_post, u_next_k)
         ↓
Phase 3：健康融合与决策 (Health Fusion & Decision)
  curve_health_k = 动态加权(curve_k)
  attn_health_k = forward_progress(predicted_attn_k)
  health_k = λ_curve × curve_health_k + λ_attn × attn_health_k
  score_final_k = score_base_k + α_t × γ × health_k
```

**D_t 分级干预机制（架构修正）**

*为什么不能只是"退回base planner"：* D_t大意味着：自我模型被现实严重纠偏，当前局部候选集可能整体都是错的。 压制health退回base planner的问题：base planner的候选集和health用的是同一批candidates，D_t大时这批candidates整体就不可信，退回planner只是换了打分方式，候选集还是那些，治标不治本。

*三级干预：*

* **Level 1（正常）：D_t < θ_low**`α_t = exp(-β · D_t_norm)`  正常调制。 health参与打分，候选集不变。
* **Level 2（异常）：θ_low ≤ D_t < θ_high** 宏观干预：扩展候选集。 把全局图里的frontier（未访问远端节点）加入候选集，和局部candidates一起打分。 语义："我可能走偏了，看看更远的地方有没有更好的选择"。不是抛弃局部，而是扩大视野。
* **Level 3（崩溃）：D_t ≥ θ_high** 宏观干预：STOP或BACKTRACK。 直接剥夺ETP在当前局部的打分权，强制回退到历史上health最高的节点。 语义："局部已经完全失去判断，只能从历史轨迹中找出路"。

*【阈值θ_low, θ_high】：* 不硬编码，通过以下方式确定： 训练时统计D_t的分布分位数（percentile）。 `θ_low = 75th percentile`, `θ_high = 95th percentile` 基于数据自适应，不依赖手动调参。

*Frontier节点的来源：* ETPNav的gmap里已经有全局图结构，未访问节点（frontier）是图里存在但还没去过的节点。 实现上：gmap_embeds里标记visited/unvisited。D_t超阈值时，把unvisited节点的特征加入候选集，不需要额外的模型，只需要一个mask操作。

#### Phase 1：当前关系状态提取 (看清现在)

物理语义： "我用当前的记忆，主动检索眼前的世界，产生对自己处境的理解。"

* **输入：** 内部（意识）：`h_post [B, D]`,  `z_post [B, D]` 外部（物质）：`x_t [B, N_views, D]`,  `g_t [B, N_nodes, D]`
* **Cross-Attention（单向，Q=内部，KV=外部）：**`Query = W_q([h_post ∥ z_post]) → [B, 1, D_attn]` （只有1个token，信息漏斗，强迫压缩成单一关系向量） `Key/Value = W_kv([x_t ∥ g_t]) → [B, N_views+N_nodes, D_attn]``s_t = MLP(CrossAttn(Q, K, V)) → [B, D]`
* **为什么单向（Q=内部，KV=外部）：** 不是"世界被动地被内部匹配"，而是"内部意识主动去检索世界"。这对应意识的主动性。双向虽然信息更全，但偏离哲学语义，第一版不做。
* **防止注意力坍缩：** 在Key/Value中加入：Positional Encoding 以及 Semantic Token Type Embedding： 视觉token → type_embed_visual 图节点token → type_embed_graph 强迫Query学会区分不同信息源。

#### Phase 2：候选条件驱动的统一关系推演 (Candidate-Conditioned Unified Rollout)

核心解决的问题：将“物理推演”与“语义演化”收束到同一个动作条件驱动的推演主干上，通过提取统一关系表示，同时服务于物理和语义的未来读出。

* **子步骤 A：构建统一关系表示 (`u_next_k`)** 首先，内部意识在自我状态空间先行演化（闭眼冥想）： `a_k = ActionEncoder(f_{t,k})``h_next_k = RSSM_Transition(h_post, z_post, a_k, L)``z_next_k = PriorNetwork(h_next_k)` 随后，使用精简版的 Decoder Layer (去除冗余的 Self-Attn) 进行统一关系推演： `q_next = query_proj([h_next_k || z_next_k])``m_next = memory_proj([x_t || g_t || f_{t,k}])` (世界联合候选特征作为条件) `c_next = CrossAttn(q_next, m_next, m_next)``r_next = LN(q_next + c_next)` (残差融合，避免完全被外部 KV 带着走) `u_next_k = LN(r_next + FFN(r_next))` (通道维非线性重组，压实为稳定状态表示)
* **子步骤 B：物理状态读出** 从统一表示中解耦出物理专属状态，进行曲线预测： `s_next_k = StateHead(u_next_k)``curve_k = CurvePredictor(s_next_k) → [B, H]`
* **子步骤 C：语义焦点读出** 从统一表示中预测未来注意力演化（需结合当前注意力锚点）： `predicted_attn_k = AttentionHead(attn_post, u_next_k) → [B, L_len]`

#### Phase 3：健康融合与决策 (Health Fusion & Decision)

核心洞察：从预测出的物理曲线和语义分布中，分别提取可量化的“健康度”标量，综合防作弊校验。

* **Step 1：动态物理健康度分解 (基于 curve_k)**`early = mean(curve_k[:, :2])``late  = mean(curve_k[:, 2:])``trend = curve_k[:, -1] - curve_k[:, 0]``[λ_e, λ_l, λ_t] = Softmax(Linear(3))`   # 熵正则化的可学习动态权重 `curve_health_k = λ_e×early + λ_l×late + λ_t×trend` （VLN关心最终到达，预期λ_l最大）
* **Step 2：语义转移健康度 (基于 predicted_attn_k)** 自然语言（尤其是英语）具有复杂的倒装、从句结构，不能用简单的绝对位置差来衡量进度。 `attn_health_k = AttnHealthScorer(predicted_attn_k, attn_post, L) → [B, 1]` （语义：通过轻量打分头学习注意力转移逻辑是否健康——焦点变得明确且符合句法依赖。）
* **Step 3：综合健康度与最终打分**`health_k = λ_curve × curve_health_k + λ_attn × attn_health_k` 物理与语义互补，杜绝“物理近但走错房间”或“原地打转假装看指令”的作弊行为。 结合 D_t 门控系数（`α_t = exp(-β · D_t_norm)`）进行最终局部重排： `score_final_k = score_base_k + α_t · γ · health_k`

### 四、训练目标

**四个Loss的对称结构** 这是整个训练设计最关键的洞察：

| 维度       | 当前步自洽                            | 跨步预测                            |
| ---------- | ------------------------------------- | ----------------------------------- |
| **物理层** | **L_kl**（belief当前步一致性）       | **L_curve**（future progress预测） |
| **语义层** | **D_t ⊂ L_kl**（KL产出的mismatch） | **L_attn**（future attention预测） |

完全对称：

* 物理层当前步（L_kl）：prior和posterior的belief一致性
* 物理层跨步（L_curve）：未来H步progress曲线预测
* 语义层当前步（D_t）：prior和posterior的attention差异（L_kl产出）
* 语义层跨步（L_attn）：未来一步attention distribution预测

L_kl已经同时覆盖物理层和语义层的当前步；L_curve和L_attn分别覆盖物理层和语义层的跨步。 **所以L_attn不是辅助正则，而是和L_curve完全对称的核心贡献。**

**最终Loss**

```text
L_total = L_planner          # 决策主线
        + λ_kl   × L_kl      # 物理+语义层 当前步自洽
        + λ_curve × L_curve  # 物理层 跨步预测
        + λ_attn  × L_attn   # 语义层 跨步预测
```

四个，完全不重叠，每个不可替代。

* **L_planner**`L_planner = CrossEntropy(score_final, GT_action)` 作用：让系统学会在ETP base score和health bonus之间权衡，隐式地让health_GT > health_non_GT（通过score_final排序）。
* **L_kl**`L_kl = KL(q(z_t | h_post, x_t, g_t) ∥ p(z_t | h_prior))` 作用双重：1. 维持RSSM prior/posterior不偏离（物理层当前步自洽）。2. 产出D_t = KL散度值（语义层当前步mismatch信号）。 D_t的语义：物理层：prior和posterior的belief gap；语义层：attn_prior和attn_post的差异投影。两者同时被L_kl约束。
* **L_curve（物理层跨步预测）**`L_curve = MSE(curve_GT_action, GT_curve)` GT的构造（包含当前步+未来步）：`GT_curve = [Δp_0, Δp_1, Δp_2, ..., Δp_H]`。加入当前步progress作为世界锚点，同时承担"关系状态的世界锚定"职责，不需要单独的L_relation。`Δp_0 = current_progress`（锚定当前在哪），`Δp_h = (d_{t+h-1} - d_{t+h}) / norm`（未来变化）。 【只在GT action上计算】：teacher forcing只走GT路径，GT action的u_next_k派生的未来曲线参与计算。 Smooth处理：moving average平滑progress_ratio，window=3，消除绕路带来的短期负progress干扰。
* **L_attn（语义层跨步预测）**`L_attn = KL(predicted_attn_k_GT ∥ actual_attn_post_{t+1})` 或 `CrossEntropy(predicted_attn_k_GT, actual_attn_post_{t+1})` GT来源：下一步实际的`attn_post_{t+1}`。RSSM correction模块已经在算，零额外标注成本，训练时teacher forcing有完整轨迹，GT是合法的。 【为什么L_attn和L_kl不冲突】：L_kl约束当前步：prior和posterior的attention一致性；L_attn约束跨步：预测下一步posterior attention会是什么。一个是当前步自洽，一个是跨步预测，完全正交，不冲突。 【为什么L_attn不应该被降级】：AttentionTransition模块没有直接监督时，几乎必然学不动。L_planner只能给attn_health间接梯度，信号极弱。L_attn是AttentionTransition能工作的必要条件，和L_curve的地位完全对称。

### 九、论文贡献

**三句话版本**

1. **第一句（问题）**：现有VLN agent没有对自身决策轨迹的预测能力，只能在退化发生后被动修正。
2. **第二句（方法）**：我们提出ASM-VLN：将自我状态定义为内部意识检索外部环境与指令后产生的关系状态；通过**候选条件驱动的统一关系推演**，利用一个无 Self-Attention 的轻量级 Decoder 块生成统一关系表征，并从中平行读出物理距离曲线与语言注意力演化；最终在 D_t 异常时触发分级宏观干预。
3. **第三句（结果）**：自我模型能在失败发生前平均X步检测到退化，分级干预在D_t崩溃场景下额外提升Y%成功率，SR整体提升Z%。

**和已有工作的清晰区分**

* **世界模型（Dreamer等）：** 预测环境状态 → 我们预测关系状态
* **Self-Monitoring (Ma'19)：** 当前步后验 → 我们未来H步先验
* **Value Function（RL）：** 标量期望 → 我们曲线形态（保留时序）
* **Progress Monitor：** 监控距离 → 我们通过“同一推演，两路读出”同步预测物理关系与语言注意力。

### 十、一句话总结

我们从"建一个自我模型"出发，在哲学上找到了和世界模型的根本区别：世界模型预测物质，我们的自我模型预测意识——agent、环境与指令交互产生的三元匹配关系状态。在技术上，以 Cross-Attention 为核心实现了“内部意识主动检索外部环境”，通过定制版 Decoder Layer 完成了**候选条件驱动的统一关系推演 (Candidate-Conditioned Unified Rollout)**，并从中优雅地双轨读出物理与语义演化健康度，结合 D_t 分级干预在系统崩溃前主动接管方向盘。这些机制共同构成一个有哲学深度、有技术实现、有可验证实验的完整框架。

### 十一、附录：核心机制深度拆解（统一推演与 Decoder 裁剪）

> 本节针对 **Phase 2 (Candidate-Conditioned Unified Rollout)** 进行工程级与逻辑级的多维度考量。

#### 1. 理论的终极大统一：为什么要合并为一个 Unified Trunk？

如果 `AttentionTransition` 只是在外部单独看一眼，失去了与“反事实推演网络”的深度绑定，就会导致物理与语义模型发生割裂。将两者合并为统一推演主干 `UnifiedRolloutTrunk`，能够彻底证明：**推演出来的 `u_next_k` 就是“我、环境、指令”这三者碰撞后产生的唯一关系母体（Mother Representation）。** 无论是后继的物理距离缩短，还是注意力的推移，都只是这个母体状态的平行外化特征。这种“一次推演，双路读出”的逻辑使得 `L_attn` 的梯度能实实在在地压回推演主干，强迫其必须学习文本对齐的推进。

#### 2. 工程实现：定制版 Decoder Layer 的精准手术

为了得到稳定且强大的统一关系表示，我们采用了经典的 Transformer Block 骨架，但做出了针对性的裁剪：

```text
# Unified Rollout Trunk 的精简逻辑
q_next = query_proj([h_next_k || z_next_k])
m_next = memory_proj([world || f_tk])

x = CrossAttn(q_next, m_next, m_next)
x = LN(q_next + x)                   # 避免完全被外部 KV 拉着走，通过残差绑定自我状态
u_next_k = LN(x + FFN(x))            # 通过 FFN 做通道维上的非线性重组
```

* **积极方面（巧妙且轻量）**：对于 VLN 任务中的内部意识 Query，通常非常短小甚至压缩至单个 Token。标准的 `nn.TransformerDecoderLayer` 默认会执行 Self-Attention，这对于单 Token 来说不仅没有意义，还会浪费算力。我们“阉割”掉 Self-Attention，仅保留 `Cross-Attn -> Residual -> LN -> FFN -> Residual -> LN` 的黄金组合。FFN 的存在至关重要，它能把 Attention 提取到的散乱上下文（Context）压实为高度稳定的状态表示，让后续的两个 Readout Head （StateHead 和 AttentionHead）读取得极其清晰。
* **消极考量（过拟合与初始化风险）**：虽然我们去掉了 Self-Attention 降低了参数量，但 LayerNorm 和 FFN 的引入如果初始化不当，可能会导致初始阶段梯度极大，或者在早期模型过于依赖跳跃连接（Residual connection）而无视了环境的 Cross-Attention。必须配合恰当的学习率 Warmup。

#### 3. O(K) 复杂度的“平行宇宙”降维（Batch Flattening）

面对 K 个候选节点，如果使用 for 循环推演会导致推理时间爆炸。我们在代码实现时将 `B` 和 `K` 展平为 `B × K` 的“大 Batch”，送入上述 Unified Trunk 中，只需执行一次高度并行的矩阵乘法，就能将 `O(K)` 的串行时间压缩为 `O(1)` 的并行时间。
